## Organización del Project

[Project de Nodo Norte](https://github.com/users/LeoAstray/projects/1):

| Vista | Uso |
| --- | --- |
| [Backlog](https://github.com/users/LeoAstray/projects/1/views/1) | Tabla con estado, responsable, horas, área, fase, tipo y prioridad. |
| [Tablero](https://github.com/users/LeoAstray/projects/1/views/2) | Trabajo diario: Por hacer, En curso y Hecho. |
| [Sprints](https://github.com/users/LeoAstray/projects/1/views/3) | Preparación, Sprint 1, Sprint 2 y Cierre; agrupación adicional por prioridad. |
| [Calendario](https://github.com/users/LeoAstray/projects/1/views/4) | Fechas de inicio y objetivo, para completar cuando estén acordadas. |
| [Mi trabajo](https://github.com/users/LeoAstray/projects/1/views/5) | Tareas asignadas a quien consulta el Project (`assignee:@me`). |
| [Áreas](https://github.com/users/LeoAstray/projects/1/views/6) | Secciones de Requisitos, Diseño, Desarrollo, Validación y Entrega. |

Campos: **Área**, **Fase**, **Tipo** (Historia de usuario, Tarea, Corrección), **Prioridad** (Alta, Media, Baja) y **Horas estimadas**; se mantienen responsables y fechas. Las horas incluyen pruebas y se acuerdan al planificar.

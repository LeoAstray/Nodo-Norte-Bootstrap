# Nodo Norte

Proyecto de Diseño de Interfaces Web: diseño y maquetación de la web de una comunidad tecnológica local con Bootstrap 5.3, trabajo en equipo con Git y organización mediante Scrum.

## Estado

Repositorio creado. Requisitos e historias recopilados, briefing preparado y documentación organizada. Briefing reducido a nueve preguntas; las respuestas se consolidarán más adelante. Pendientes: configuración de GitHub Projects, Product Backlog y desarrollo de la web. Las demás dudas se resolverán cuando se necesiten.
